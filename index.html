PlaySync pour Emby

Partagez vos listes « À voir » entre comptes Emby

PlaySync retire automatiquement les médias vus d'une playlist partagée et synchronise l'avancement de lecture entre ses membres — sans jamais perdre le fil de qui a vu quoi.

Voir sur GitHub Téléchargements
Le constat

Une liste « à voir » partagée devient vite ingérable

Sur un serveur Emby personnel ou familial, chaque compte gère sa propre liste. Sans coordination, elle accumule doublons, oublis et médias déjà vus.

🗂️

Doublons et oublis

Chacun ajoute les mêmes médias sans savoir ce que les autres membres du foyer ont déjà regardé.

🧹

Retrait manuel

Un média regardé reste dans la liste partagée : il faut penser à le retirer soi-même, pour tout le monde.

⏱️

Progression perdue

Changer de compte ou d'appareil en cours de visionnage fait perdre la position de lecture.

La réponse

Ce que fait PlaySync

PlaySync s'appuie sur le partage natif de playlists d'Emby et y ajoute la gestion automatique de l'état « vu », activable par étiquette, playlist par playlist.

🔗

Partage natif, sans friction Nouveau v1.0.0

Le partage passe par le menu Emby standard. La permission nécessaire côté propriétaire est accordée automatiquement à tous les comptes.

✅

Retrait automatique du média lu Nouveau v1.0.0

Étiquette remove-si-lu : quand un membre termine un média, il disparaît de la liste pour tout le monde.

🔄

Progression partagée Nouveau v1.0.0

Étiquette propager-lu : le flag lu et la position de lecture sont copiés chez les autres membres — commencez sur un compte, poursuivez sur l'autre.

📊

Diagnostics intégrés Nouveau v1.0.0

Journal des décisions et état en mémoire consultables par un administrateur ; comportement vérifié à l'échelle (10+ playlists, 5+ membres simultanés, latence sous 1 s).

👤

Page utilisateur dédiée Nouveau v1.1.0

Une page « PlaySync » dans le menu Emby (Avatar → PlaySync) pour gérer membres et options de partage sans toucher aux étiquettes : ajout, niveau Lecture/Écriture, retrait, interrupteurs — en français et en anglais.

Sous le capot

Un plugin, sans service additionnel

PlaySync s'exécute à l'intérieur du processus Emby Server : il écoute les événements natifs (lecture, playlists) et réagit en conséquence, sans base de données ni serveur séparé.

C# / .NET 6 Plugin Emby natif Aucune base de données Aucun frontend dédié — page de config Emby

Prérequis : un serveur Emby existant (testé sur le SDK 4.9.3.0). Le plugin s'installe sur l'instance déjà en place, sans infrastructure supplémentaire.

Mise en place

Installer PlaySync

# Cloner le dépôt
git clone https://github.com/CCoupel/Emby_PlaySync.git
cd Emby_PlaySync

# Compiler
dotnet build src/EmbySharedPlaylist/EmbySharedPlaylist.csproj \
  --configuration Release --output dist/

# Installer
cp dist/EmbySharedPlaylist.dll /config/plugins/
# puis redémarrer Emby
PlateformeFichierInstallation
Toutes (partout où Emby Server tourne) EmbySharedPlaylist.dll Copier dans le dossier plugins/ d'Emby (racine, pas de sous-dossier), puis redémarrer.

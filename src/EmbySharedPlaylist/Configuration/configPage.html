Paramètres PlaySync

Une playlist « À voir » devient partagée via le partage natif d'Emby : menu « … » de la playlist → Gérer la collaboration. Depuis la v1.1.0, le propriétaire dispose aussi d'une page dédiée « PlaySync » (menu utilisateur, Avatar en haut à droite) pour gérer les membres et les options plus facilement. Ce plugin ajoute deux comportements réglés par étiquette (Modifier les métadonnées → Mot-clé, sur la playlist elle-même), à NON par défaut (rien ne change) — pour activer une option, remplacez NON par OUI :

  • remove-si-lu=OUI : un média qui passe à « lu » est retiré de la playlist.
  • propager-lu=OUI : le flag « lu » et l'avancement de lecture (position) sont propagés aux autres membres.

La permission de partage (« Permettre le partage de contenus personnels ») peut être accordée automatiquement par le plugin pour tous les comptes, via la case « Activer le partage automatiquement » ci-dessous — désactivée par défaut (un élargissement de droits pour tous les comptes n'est pas activé sans décision explicite, en particulier sur un serveur exposé). Si vous l'activez : limite connue — un administrateur qui retire cette permission manuellement pour un compte précis la voit réappliquée à la passe suivante (le plugin ne mémorise pas ce retrait) — seul le décochage de la case ci-dessous empêche cette repose pour tous les comptes.

Limites connues : le comportement dépend du client utilisé pour la lecture (confirmé sur le client web ; TV/mobile non entièrement vérifiés à ce jour).

Nombre de passes de réconciliation consécutives sans étiquette (ou avec une description vide) avant que le plugin repose la valeur par défaut. Défaut : 2, minimum : 1. La période des passes se règle dans les tâches planifiées d'Emby.
Pose Policy.AllowSharingPersonalItems=true pour tous les comptes (existants et nouveaux), au démarrage, à la réconciliation périodique et à la création d'un compte. Désactivé (défaut) : aucune écriture. Dans tous les cas, une fois activé : ne révoque jamais un accès déjà accordé, même si vous décochez ensuite cette case.
Expose /SharedPlaylist/Diagnostics/* (journal des décisions et état en mémoire, identifiants seulement).
Lignes préfixées [EmbySharedPlaylist], visibles par kubectl logs (en plus du fichier de journal d'Emby).
